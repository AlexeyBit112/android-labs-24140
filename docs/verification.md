# Проверка лабораторных работ

Дата проверки: 1 ноября 2026 года.

Сборка выполнена без установки Android Studio. Использованы JDK 17.0.19, Gradle 8.7, Android Gradle Plugin 8.5.2 и уже установленный Android SDK. Приложения запускались на Android Emulator: Android 15, API 35, профиль Pixel 7, 1080 × 2400.

Это четыре сценарных теста с последовательностями действий и несколькими проверками внутри каждого. Они проверяют результат в интерфейсе, а не только запуск Activity. Предупреждения lint включают тексты в XML, подсказки autofill, особенности разметки и наличие более новых версий зависимостей. Версии проекта закреплены; предупреждения не скрываются настройками lint.

## Проверенные сценарии

- Лаба 1: вывод Hello World.
- Лаба 2: пустое имя, пустой и неподходящий возраст, переполнение Int, нечисловой ввод, согласие с правилами, успешная отправка, передача Unicode-текста через Intent и возврат с результатом.
- Лаба 3: отсутствие данных, пустой ввод, сохранение и загрузка SharedPreferences, очистка, сохранение и загрузка файла, настоящие ошибки чтения и записи, добавление трёх строк, удаление средней строки и поворот экрана.
- Лаба 4: SQLite CRUD, текст с кавычками, отсутствующий ID, проверка заголовка и выбора записи, добавление, выбор, изменение, удаление, пересоздание Activity и поворот с сохранением выбора.

Дополнительный сценарий `scripts/check-persistence.py` проверил SharedPreferences, файл и SQLite после `am force-stop` и нового запуска процесса. Все три проверки завершились успешно.

## Сборка и воспроизведение

`assembleDebug` и `lintDebug` завершились успешно для всех модулей. Инструментальные проверки выполнены через `connectedDebugAndroidTest`. После исправления очереди Toast тесты затронутых модулей 2–4 выполнены повторно. После форматирования XML повторно выполнены сборка и lint. Команды для самостоятельного запуска приведены в README.

В отчётах размещены 33 настоящих скриншота. Основные снимки сняты через `UiDevice.takeScreenshot`, три снимка проверки перезапуска — через `adb exec-out screencap -p`. Содержимое изображений не редактировалось.

Проверка выполнена на одном профиле эмулятора с API 35. Минимальный API 24 указан в проекте, но отдельного запуска на Android 7 в этом прогоне не было.

Для лабы 1 объём Hello World принят из предоставленного описания. Для лабы 4 реализована предоставленная часть 1. Отдельные темы практических работ в присланной переписке отсутствуют.
